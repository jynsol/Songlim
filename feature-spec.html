스크랩에서 관심을 모으고, 오늘에서 하나를 선택해 기록한다. 완료한 경험은 나의 숲에 나무로 남으며 공유는 숲에서 선택한다.

하단 탭주요 기능

하단 탭 순서는 오늘 · 스크랩 · 나의 숲 · MY다. 네 탭의 기본 화면에는 같은 위치에 ＋ 스크랩을 고정한다. 입력창·인증·공유 미리보기에서는 숨긴다.

보기 쉽고 편한 흐름으로 정리

핵심 구조와 기능은 유지한다. 일일 기록은 한 번에 실행하고, 같은 결과를 여러 화면에서 다시 확인하지 않게 한다. 아래 번호는 화면·상태·패널의 설계 참조이며 모두 별도 페이지로 만들라는 뜻이 아니다.

영역반영한 정리
오늘성장 이미지·작품·기록 버튼을 한 흐름으로 묶는다. 전체 완료는 작은 텍스트, 콘텐츠 변경은 더보기로 둔다. 기록 후와 전체 완료 후는 현재 화면의 상태 교체다.
상세미완료·당일 기록·완료 상태에 맞는 행동만 표시한다. 최근 기록부터 보여주고 과거 기록·출처 정보는 펼쳐 본다. 평가와 삭제를 항상 함께 노출하지 않는다.
스크랩 입력추가 방법 선택→해당 입력을 같은 하단 패널 안에서 이어간다. 분석·성공·오류는 상태 교체다. 여러 사진의 후보 확인만 목록 검토 화면으로 유지한다.
가끔 쓰는 동작기록 수정·평가·필터·연월 선택은 패널 또는 메뉴로 처리한다. 연월은 선택 즉시 반영하고 별도 확인 단계를 늘리지 않는다.
유지할 화면숲·달력·공유의 역할은 구분해 유지한다. 작은 동물·테마·4:5 공유와 번호별 기능 설명도 유지한다.

번호선·외곽선은 문서의 설명 장치다. 실제 앱에서는 번호가 표시되지 않는다. 보조 텍스트도 터치 영역은 44×44 이상 확보한다.

목업 반영 · 시각 방향과 정보 우선순위

제공된 목업의 큰 성장 이미지와 입체적인 숲, 둥근 카드를 시각 방향으로 삼는다. 문서는 흰 배경·검정 본문·회색 보조와 얇은 구분선을 기본으로 한다. 주요 버튼에만 목업의 파랑–청록 그라데이션을 사용하고, 선택 표시는 파랑으로 작게 강조한다. 보조 버튼과 문서 배경은 무채색으로 유지한다. 아래 화면 예시는 기능과 배열을 설명하는 와이어프레임이며 문서와 화면 예시에도 같은 포인트 색상·카드·버튼 스타일을 적용한다. 배경·표·설명 번호에는 색을 넓게 깔지 않는다. 숲과 성장 삽화의 색은 유지한다.

화면유지정리
오늘성장 이미지 하나, 제목·제작자, 오늘 기록 버튼스크랩 횟수·장르 배지와 상시 성장 설명 카드는 상세 또는 첫 이용 안내로 옮긴다. 성장 단계는 이미지 아래 짧은 문구 하나만 쓴다. 연속 일수 배지는 기본 화면에 추가하지 않는다. 전체 완료는 보조 텍스트, 작품 변경은 더보기에 둔다.
나의 숲입체 숲, 연도 선택, 공유, 월간 기록·테마영문 SCALE COMPARISON과 비교 대상 눈금·진행 막대는 제외한다. 숲 아래 비교 문구와 경험 수·현재 가상 면적을 표시하고 유형별 수는 작은 보조 텍스트로 묶는다. 숲은 직접 확대·이동하므로 별도 둘러보기 버튼 없이 짧게 안내한다.
스크랩작품 표지, 상태 필터, 검색, 정렬, 스크랩 추가검색창이 있는 화면에서는 상단 검색 아이콘을 중복 제공하지 않는다. 유형은 표지 위 아이콘과 배지 중 한 방식만 쓴다. 스크랩 횟수는 작은 보조 정보로 두고 메모는 최대 한 줄로 자른다. ‘경험 중’은 음반에도 통하는 ‘경험 중’으로 통일한다.
월간 기록달력·완료일 표지, 월간 요약, 공유목업의 구성은 유지한다. 나의 숲에서 진입하므로 하단 활성 탭은 나의 숲이다. 오늘 날짜 강조와 완료 기록 표시는 구별하고 색만으로 상태를 전달하지 않는다.
공통 상단화면 제목과 필요한 작업하단 MY와 중복되는 프로필 아이콘은 기본 상단에서 제외한다. 알림 아이콘은 현재 정의된 알림 기능이 필요한 화면에서만 사용하며 장식으로 추가하지 않는다. 모든 화면에 검색·추가·알림을 일괄 배치하지 않는다.

‘4일째 함께 읽는 중’은 연속 기록을 암시할 수 있어 기본에서 제외한다. 최초 기록일 이후 경과일과 실제 기록한 날 수를 혼용하지 않는다. 성장 조건은 기존대로 서로 다른 날의 기록과 전체 완료에 따른다. 일반 기록이 아니라 전체 완료 때 나의 숲에 한 그루가 추가된다.

정보 확인후보 콘텐츠와 확정 버튼을 먼저 표시한다. 다른 후보 또는 직접 수정을 선택했을 때만 해당 입력을 펼친다.

4. 오늘

오늘은 선택한 콘텐츠의 성장 이미지 하나와 제목·제작자·기록 버튼을 표시한다. 표지는 넣지 않는다. 스크랩 이유와 마지막 기록은 필요한 경우 작은 보조 텍스트로 둔다. 스크랩·콘텐츠 상세·월간 달력의 표지는 유지한다.

상태화면과 행동
선택 전‘오늘 뭐부터 해볼까요?’ 아래에 스크랩한 후보 하나를 보여준다. 이 콘텐츠 선택하기를 대표 행동으로, 다른 스크랩 보기를 작은 텍스트로 제공하고 직접 고르기는 더보기에 둔다. 선택은 기록을 생성하지 않는다.
선택 후같은 카드에서 오늘의 독서·음악·영화에 맞는 기록 버튼 하나를 강조하고 전체 완료는 작은 텍스트로 제공한다. 다른 콘텐츠로 바꾸기는 제목 옆 더보기로 모은다. 스크랩 이유는 작은 보조 문구로 둔다. 선택은 날짜가 바뀌어도 유지한다.
일일 기록 후현재 기록 버튼 자리에 ‘오늘 기록했어요’와 취소를 표시한다. 별도 페이지로 이동하지 않는다. 기록 수정 선택 시 날짜·페이지·메모를 펼친다.
완료 후현재 성장 이미지를 나무로 바꾸고 ‘나의 숲에 나무가 더해졌어요’와 내 숲 보기를 대표 버튼으로, 다음 스크랩 고르기를 작은 텍스트로 표시한다. 취소는 작은 보조 동작으로 유지한다. 자동으로 다른 화면이나 다음 콘텐츠로 이동하지 않는다. 면적 증가·새 단계 알림·공유·평가를 이 화면에 함께 표시하지 않는다. 공유는 나의 숲에서, 평가는 콘텐츠 상세에서 선택적으로 진행한다. 내 숲 보기는 실제 완료일의 연도를 연다.
다른 스크랩 선택스크랩 목록을 선택 모드로 연다. 아직 안 본 것·경험 중에서 고르며 이전 기록은 유지한다. 후보는 스크랩 횟수 내림차순, 최근 스크랩일 내림차순으로 정렬한다.
후보 없음스크랩 추가를 안내한다. 스크랩하지 않은 외부 콘텐츠를 자동으로 제안하지 않는다. 후보가 하나면 다른 스크랩 보기 버튼을 숨긴다.

5. 콘텐츠 상세

구성기능
기본 정보제목·제작자·현재 상태를 먼저 표시하고 표지는 작은 썸네일로 유지할 수 있다. 출처·횟수·서점·음악·시청 링크는 콘텐츠 정보 안에 접어둔다. 기본 정보 수정·삭제는 더보기로 모은다.
경험 행동오늘 화면과 같은 기록 처리를 사용하되 현재 상태에 맞는 대표 행동 하나만 표시한다. 미완료 콘텐츠는 기록 버튼과 작은 완료 텍스트, 당일 기록 후는 결과·수정·취소, 완료 콘텐츠는 완료일·평가를 표시한다. 서로 다른 상태의 버튼을 동시에 나열하지 않는다.
기록최근 기록 하나를 먼저 보여주고 지난 기록 보기를 펼쳐 날짜별 경험 기록을 확인한다. 행의 수정에서 페이지·메모·날짜를 편집·취소한다. 완료일·평가는 완료한 콘텐츠에만 제공한다. 날짜는 오늘이 기본이며 과거로 변경할 수 있다.
정보 수정잘못 식별된 기본 정보와 후보를 수정한다.
삭제해당 스크랩과 관련 경험 기록이 함께 삭제됨을 안내하고 확인을 받는다. 다른 사용자의 콘텐츠에는 영향을 주지 않는다.

6. 나의 숲

완료한 고유 콘텐츠 하나마다 나무 한 그루가 더해지는 하나의 숲을 보여준다. 숲 아래의 텍스트로 크기를 비교하며, 운동장·건물 이미지나 별도의 면적 보기 화면은 두지 않는다.

화면 구성기능
연도현재 연도가 기본이다. ‘2026년 나의 숲 ▾’에서 연도를 바꾸면 같은 화면에 해당 연도 숲을 표시한다. 별도 연도 갤러리나 〈 〉 개별 기록 탐색은 추가하지 않는다.
숲 이미지선택 연도의 완료 콘텐츠 N개에 나무 N그루를 일대일로 대응한다. 나무를 하나씩 추가할 수 있는 정적 요소로 구성하고, 이전 나무 위치는 가능한 한 유지한다. 전체 숲을 화면에 맞추며 완료량이 많아지면 배치 영역과 밀도로 누적을 표현한다. 단계별 완성 그림 교체나 5개마다 새 이미지 해금은 사용하지 않는다.
규모숲 아래에 크기 비교 문구와 실제 가상 면적·완료 수를 표시하고 유형별 수는 작게 둔다. 나무·꾸미기 이외의 별도 대표 이미지는 넣지 않는다.
공유내 숲 공유하기로 현재 연도·숲·테마·집계를 담은 미리보기를 연다. 완료 0개일 때는 공유를 비활성화한다.
보조 메뉴월간 기록 / 테마. 개별 콘텐츠의 확인·수정은 월간 달력 또는 스크랩·상세에서 한다. 숲의 핀치 확대·드래그 이동은 감상을 위한 동작으로 제공한다. 나무·동물 터치로 상세를 열거나 별도 기록 탐색 버튼을 추가하지 않는다.

완료와 나무의 관계

  • ‘나의 숲에 나무가 더해졌어요’는 유효 완료 한 건과 그에 대응하는 나무 한 그루가 추가되었다는 뜻이다. 완료마다 실제 나무 수가 증가한다.
  • 면적은 선택 연도의 완료 고유 콘텐츠 수 × 15㎡다. 스크랩·일일 기록·완료 재클릭·같은 작품 재경험으로 늘리지 않는다. 화분·장식·배경 요소는 나무 수에 포함하지 않는다.
  • 미완료 씨앗·싹·덤불은 나의 숲에 표시하지 않는다. 0개는 빈 숲과 0㎡, 첫 경험 안내를 보여준다. 첫 완료의 ‘화분 하나에 심어졌어요’는 시작 안내로만 쓰며 15㎡가 실제 화분 면적이라는 의미로 사용하지 않는다.
  • ‘다음 숲까지 n개’와 새 단계 알림은 없다. 새해에는 새로운 숲을 시작하고 지난 숲은 연도 메뉴에서 확인한다.
  • 완료 취소·삭제 시 대응 나무를 제거하고 면적·비교 문구를 함께 갱신한다. 완료일의 연도가 바뀌면 이전·새 연도 모두 반영한다. 날짜 미상 완료는 전체 완료 목록에 남기되 연도 숲에는 포함하지 않는다.

면적 비교 · 5그루마다 갱신

나무와 면적 숫자는 완료마다 늘어난다. 비교 문구는 5·10·15·20그루…마다 그때의 면적과 가장 가까운 대상으로 갱신하고, ‘{대상}만큼 넓어졌어요’로 표시한다. 비교 대상 그림은 추가하지 않는다.

상태처리
0개0㎡와 첫 경험 안내. 비교 문구와 공유는 숨기거나 비활성화한다.
1–4개‘화분 하나에 심어졌어요’라는 시작 문구를 유지한다. 숫자는 15·30·45·60㎡로 증가한다. 화분의 실제 면적을 뜻하지 않는다.
5개 이상기준 완료 수 = floor(현재 완료 수 ÷ 5) × 5. 그 기준 수 × 15㎡와 절대 면적 차이가 가장 작은 활성 대상을 고른다. 차이가 같으면 작은 기준면적을 우선한다. 현재 면적보다 큰 대상도 선택할 수 있다.
예시10–14개에서는 10개 시점의 150㎡를 기준으로 선택한 문구를 유지한다. 실제 면적 숫자는 150→210㎡로 계속 늘어난다. 15개에서 225㎡에 가장 가까운 대상을 다시 고른다.
비교 대상작은 화단·텃밭·뒷마당·놀이터·농구장·축구장·지역 등 이름·기준면적·출처 또는 서비스 설정 근거·활성 여부를 관리한다. 초반 비교 기준을 촘촘하게 준비한다. 실제 수치는 별도 확정하며 같은 대상을 다시 고르면 문구는 유지한다. 변화를 만들기 위해 근사하지 않은 대상을 강제로 선택하지 않는다.
정정·공유취소·삭제·완료 연도 변경 시 해당 연도의 기준 구간을 다시 계산한다. 연도 이동·공유 재진입만으로 문구를 바꾸지 않는다. 숲 화면과 공유 이미지는 같은 기준 버전과 문구를 사용한다.

화면과 공유 카드에 ‘완료한 경험을 환산한 가상 면적’을 작게 표시한다. 동일·초과 여부에 따른 문장 분기는 사용하지 않는다.

확대와 작은 환경 움직임 · MVP 범위

항목동작 기준
기본 화면첫 진입과 연도 변경 시 전체 숲을 화면에 맞춘다. 전체에서는 나무의 누적이 먼저 보이고, 확대하면 작은 동물과 장식을 발견할 수 있게 한다. 면적·비교 문구·메뉴는 숲 밖에 고정하여 확대 대상에서 제외한다.
확대·이동숲 영역 안에서 핀치 확대와 드래그 이동을 제공한다. 배율은 전체 맞춤을 최솟값으로 하며 최댓값은 나무·동물이 흐려지지 않는 원본 해상도로 제한한다. 빈 공간으로 벗어나지 않도록 이동 범위를 제한한다. 숲 영역 밖에서는 페이지 스크롤을 유지한다. 확대 상태에만 작은 ‘전체 보기’를 표시한다. 마우스 휠·드래그와 키보드 확대·축소·이동도 같은 동작에 대응시킨다.
복귀공유 미리보기·테마 메뉴·월간 기록에서 돌아오면 같은 연도의 배율·위치를 유지한다. 다른 연도를 선택하면 전체 보기로 시작한다. 확대 자체는 완료나 성장 기록을 만들지 않는다.
동물초기에는 1~2종, 화면 내 동시 배치는 최대 2마리로 제한한다. 정해진 짧은 경로를 천천히 이동하거나 잠시 머문다. 확대한다고 새 동물을 생성하지 않는다. 완료 수와 무관한 환경 요소이며 나무·면적 집계에서 제외한다. 빈 숲에는 표시하지 않는다.
환경 애니메이션일부 잎·장식에만 작은 반복 움직임을 적용한다. 모든 나무를 동시에 흔들거나 자동으로 화면을 이동하지 않는다. 동물 조작·먹이·수집·보상·소리·미니게임은 포함하지 않는다. 오늘의 기록 버튼과 완료 안내는 이 연출을 기다리지 않는다.
성능과 접근성화면 밖과 다른 탭에서는 움직임을 중지한다. 기기의 동작 줄이기 설정을 존중하고 성능이 부족하면 움직임을 정지 이미지로 낮춘다. 동물·숲·나무 수는 그대로 유지한다. 장식에 자동 초점을 주지 않으며 확대·이동 없이도 기록과 공유를 이용할 수 있다.

그림 제작과 배치 기준

기본 테마 하나에 같은 시점·광원의 투명 배경 나무 약 10종과 깊이감 있는 배경을 준비한다. 10종은 그림의 종류이며 완료 상한이 아니다. 콘텐츠마다 나무 종류·위치를 고정해 재진입 시 무작위로 바뀌지 않게 한다. 뒤쪽은 작게, 앞쪽은 크게 배치하고 앞뒤 순서대로 겹친다. 배경은 하늘·먼 산·안개·지면 중심이며 별도로 셀 수 있는 기록 나무를 추가하지 않는다.

먼저 10·30·100그루 장면을 비교하고 200그루에서도 식별과 확대·이동 성능을 확인한다. 100그루에서 완료 집계를 자르거나 배치를 멈추지 않는다. 테마마다 나무 10종을 새로 그리는 것은 필수가 아니며, 같은 나무에 단풍·눈·장식을 적용하고 배경을 바꾸어 재사용할 수 있다. 나무 종류에 희귀도나 수집 조건을 부여하지 않는다.

테마·꾸미기

현재 숲 위에 조명·오너먼트·선물 등의 정적 장식을 더한다. 나무 수·콘텐츠 대응·가상 면적은 바꾸지 않는다. 테마 선택과 기본으로 돌아가기를 제공하고 선택값은 연도별로 유지한다. 나무가 추가되어도 장식과 테마는 유지하고 배치만 필요한 범위에서 조정한다. 같은 테마를 공유 이미지에도 적용한다. 일부 잎의 작은 흔들림과 동물 1~2종의 느린 이동을 제한적으로 제공한다. 완료 수에 따른 동물 증가·캐릭터 수집·별도 해금 화면은 두지 않는다.

7. 월간 기록

구성기능
월 이동현재 월이 기본이다. 이전·다음 월과 월 선택을 제공한다. 미래 월은 선택하지 않는다.
이미지 달력월 선택 바로 아래에 배치한다. 콘텐츠를 완료한 날짜에 표지를 표시한다. 기록 없는 날짜는 비워둔다.
콘텐츠 열기하나인 날은 표지를 누르면 바로 상세로 이동한다. 여러 개인 날은 겹친 표지와 +n을 표시하고 날짜별 선택 목록을 연다. 상세에서 돌아오면 월·스크롤을 유지한다.
요약달력 아래에 완료 수와 책·음반·영화별 수를 한 줄로 표시한다. 주차 그래프·월 전체 완료 목록·스크랩 수는 배치하지 않는다.
공유이번 달 기록 공유하기를 제공한다. 해당 월의 달력과 요약을 이미지로 만든다. 완료 기록이 없으면 공유를 비활성화한다.
