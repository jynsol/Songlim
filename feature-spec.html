구현 전 공통으로 확인할 규칙

1. 핵심 데이터

MVP 콘텐츠 범위BOOK / ALBUM / MOVIE. 화면 표기는 책 / 음반 / 영화로 통일한다. TRACK은 음반의 오늘의 곡에서만 사용하는 하위 단위다.
Content콘텐츠 원본 엔티티. type = BOOK / ALBUM / MOVIE. TRACK은 ALBUM의 ‘오늘의 곡’에서만 사용하는 하위 단위.
UserContent사용자와 콘텐츠의 관계. status = INTERESTED / IN_PROGRESS / EXPERIENCED / DISLIKE. 온보딩의 건너뛰기는 저장하지 않는다. 스크랩·금주의 추천·나의 숲·완료 기록은 모두 동일한 UserContent를 참조하며, 화면별로 별도 콘텐츠/완료 레코드를 복제하지 않는다. 관심 저장 이력은 save_count / first_saved_at / last_saved_at으로 관리한다.
현재 추천사용자가 경험을 시작한 콘텐츠 1개. 별도 추천 콘텐츠를 새로 생성하지 않고 UserContent의 경험 전 콘텐츠를 사용한다.
성장 상태씨앗 → 싹 → 덤불 → 나무 → 큰 나무. 책의 ‘오늘 독서 완료’와 음반의 일일 경험 기록으로는 나무까지만 성장하며, 큰 나무는 콘텐츠별 최종 감상 완료 액션에서만 가능.
기간별 기록 기준월간 기록과 연도별 경험 수 집계는 사용자 로컬 날짜를 기준으로 한다. 월간 저장 콘텐츠 수는 해당 월에 counted SaveEvent가 1회 이상 발생한 고유 content_id 수, 월간 경험 수와 연도별 총 경험 수는 해당 기간에 completed_at이 존재하는 EXPERIENCED 고유 content_id 수로 집계한다. 반복 저장 횟수는 별도 관심 강도 신호로 유지한다.
숲의 연도 귀속완료 콘텐츠는 completed_at의 연도에 귀속한다. 현재 IN_PROGRESS 콘텐츠는 현재 연도의 ‘올해의 숲’에 성장 중 개체로 임시 표시하며, 과거 연도의 숲 기록에는 완료된 콘텐츠만 남긴다.
연도별 숲 테마MVP에서는 연도마다 하나의 기본 숲 디자인을 사용하고 같은 연도의 사용자는 동일한 기본 테마를 본다. 책·음반·영화 비율이나 사용자 행동 데이터에 따라 숲 테마·배경·개체 디자인이 달라지는 기능은 포함하지 않는다.
과거 숲 스냅샷연도 종료 시 forest_year / forest_theme_id / theme_version과 숲 장면 asset 참조값을 보존한다. 과거 연도는 동일 theme_version으로 재현한다.

2. 상태 전이

관심 표시 / 외부 저장INTERESTED(경험 전)
동일 콘텐츠 반복 저장새 UserContent를 만들지 않고 save_count +1, last_saved_at 갱신. 기존 상태는 유지한다. 동일 IMPORT Batch 안에서 화면 겹침 등으로 같은 콘텐츠가 여러 번 검출된 경우에는 1회만 계산한다.
경험 시작하기INTERESTED → IN_PROGRESS · 성장 상태 씨앗 생성
오늘의 경험 기록책·음반만 적용한다. 사용자 로컬 날짜 기준 하루 최대 1회 성장하며 씨앗 → 싹 → 덤불 → 나무까지만 진행한다. 영화는 일일 성장 단계를 두지 않는다.
최종 감상 완료책 ‘이 책 감상 완료’ / 음반 ‘이 앨범 감상 완료’ / 영화 ‘이 작품 감상 완료’. 현재 성장 단계와 관계없이 EXPERIENCED + 큰 나무로 처리하고 completed_at을 기록한다. 해당 완료 기록은 현재 연도 ‘올해의 숲’과 선택 월의 ‘월간 기록’에 즉시 반영되며, 연도가 바뀌면 해당 연도의 ‘숲 기록’에서 계속 열람할 수 있다.
평가완료 후 1~5점 선택 입력. 건너뛸 수 있고 완료 기록 상세에서 나중에 입력/수정 가능.

3. 콘텐츠 유형별 경험 로직

책경험 시작 후 ‘오늘의 페이지’를 보여주며, 해당 영역 안에 책 표지·제목·저자 정보를 표시한다. 별도의 감성 문구를 책 정보 대신 사용하지 않는다. 행동은 ① ‘서점 페이지’ ② ‘오늘 독서 완료’ ③ ‘이 책 감상 완료’로 구성한다. ‘서점 페이지’는 외부 서점의 구매·정보 확인 페이지로 연결한다. ‘오늘 독서 완료’는 사용자 로컬 날짜 기준 하루 1회 성장에 반영한다. 책 전체를 다 읽었다면 언제든 ‘이 책 감상 완료’를 눌러 EXPERIENCED + 큰 나무로 완료할 수 있다.
음반경험 시작 후 ‘오늘의 곡’을 보여준다. 행동은 ① ‘이 곡 듣기’ ② ‘다음 곡’ ③ ‘이 앨범 감상 완료’로 구성한다. ‘이 곡 듣기’는 Spotify 등 외부 음원 서비스의 해당 곡 재생 페이지로 연결한다. ‘다음 곡’은 오늘의 곡을 다른 곡으로 변경하는 동작이며 자체로는 성장이나 완료 처리하지 않는다. 음반의 일일 경험은 사용자 로컬 날짜 기준 하루 1회 성장에 반영하며, 앨범 전체 감상을 마쳤다면 ‘이 앨범 감상 완료’를 눌러 EXPERIENCED + 큰 나무로 완료한다.
영화책·음반과 달리 일일 성장 단계를 두지 않는다. 행동은 ① ‘보러가기’ ② ‘이 작품 감상 완료’로 구성한다. ‘보러가기’는 OTT 등 외부 시청처 또는 검색 페이지로 연결한다. 영화를 다 본 뒤 ‘이 작품 감상 완료’를 누르면 바로 EXPERIENCED + 큰 나무로 완료한다.
최종 완료 버튼콘텐츠 유형에 따라 문구를 구분한다. 책은 ‘이 책 감상 완료’, 음반은 ‘이 앨범 감상 완료’, 영화는 ‘이 작품 감상 완료’를 사용한다. 실행 시 현재 성장 단계와 관계없이 EXPERIENCED + 큰 나무로 처리한다.

3.1 반복 저장 신호

표시스크랩 카드·콘텐츠 상세·금주의 추천 이유에 ‘n번 저장’을 사용한다.
우선순위추천과 ‘내가 직접 고르기’, 스크랩 기본 정렬은 save_count DESC → last_saved_at DESC.
의미한 번 저장한 것은 관심, 반복 저장한 것은 더 강한 관심으로 해석한다.
중복 예외같은 IMPORT Batch 안의 화면 겹침·중복 검출은 1회만 계산하고, 서로 다른 시점의 의도적 저장은 각각 1회로 계산한다.
기간 집계월간 상단의 ‘저장한 콘텐츠’ 숫자는 같은 콘텐츠를 여러 번 저장해도 고유 콘텐츠 1개로 센다. 반복 저장 횟수는 ‘가장 많이 저장한 콘텐츠’와 추천 우선순위 계산에 별도로 사용한다.

4. 금주의 추천 규칙

  • 후보는 사용자가 직접 관심을 표시하거나 저장한 INTERESTED 콘텐츠만 사용한다.
  • 기본 후보 우선순위는 save_count 높은 순 → last_saved_at 최근 순으로 한다. 한 번 저장한 것은 관심, 반복 저장한 것은 더 강한 관심 신호로 해석한다.
  • 추천 카드에는 반복 저장된 콘텐츠라면 “이 콘텐츠를 n번 저장했어요”를 노출해 추천 이유를 사용자가 이해할 수 있게 한다.
  • 사용자가 저장하지 않은 새 콘텐츠를 송림이 임의로 추천하지 않는다.
  • ‘이번에는 넘기기’는 현재 후보를 해당 추천 세션에서 제외하고 다음 후보 1개를 보여주는 동작이다. 같은 세션에서 넘긴 후보는 반복 노출하지 않는다. 남은 후보가 없으면 ‘이번 추천은 여기까지’ 상태와 ‘처음부터 다시 보기’를 제공한다. 후보가 1개뿐이면 넘기기를 노출하지 않는다.
  • 경험을 시작하면 해당 콘텐츠가 현재 경험 콘텐츠가 되며 나의 숲에도 성장 중 상태로 표시한다.
  • 완료하면 현재 추천 상태를 종료하고 다음 후보를 확인할 수 있다.

5. 공통 예외 처리

  • 공유 콘텐츠 자동 인식 신뢰도가 낮거나 정보가 부족하면 사용자 확인/수정 화면으로 보낸다.
  • 동일 콘텐츠가 이미 저장되어 있으면 새 항목을 중복 생성하지 않고 기존 UserContent에 연결하며, 새로운 의도적 저장 행동 1회로 save_count를 증가시킨다. 단, 같은 IMPORT Batch 안의 중복 검출은 1회만 계산한다.
  • 오늘의 경험을 같은 날 반복 입력해도 성장 상태는 추가로 증가하지 않는다.
  • 추천 후보가 없으면 빈 상태를 보여주고 스크랩 추가를 안내한다.
  • 온보딩은 최소 응답 기준 충족 후 바로 종료할 수 있으며, 별도 완료 화면 없이 금주의 추천으로 이동한다.
날짜 기준사용자 로컬 날짜 기준 1일 1회 성장
나의 숲 표현화면보다 큰 하나의 2D 숲 장면. 사용자는 하나의 큰 숲 이미지를 뷰포트로 들여다보듯 상하좌우로 드래그/스와이프하며 숲 전체를 감상한다. 경험 중 콘텐츠는 현재 성장 단계로, 완료 콘텐츠는 큰 나무 상태로 같은 숲 장면 안에 함께 표시한다.
숲 범위나의 숲은 실제 콘텐츠 경험의 누적을 보여주는 기록 시각화다. 별도의 사용자 캐릭터나 위치 이동 요소 없이, 사용자가 화면보다 큰 숲 장면 자체를 상하좌우로 탐색한다. 점프·레벨·아이템·도감·수집·보상·재화·퀘스트는 포함하지 않는다. 새·토끼·개구리 등 작은 동물은 숲의 환경 요소로 일부 방문에서 가볍게 랜덤 노출할 수 있다. 숲이 깊어질수록 숲에서 나타나는 애니메이션이 다양해진다. 동물은 수집·보상·성장 조건과 연결하지 않고 숲을 보는 재미를 더하는 비필수 연출로만 사용한다.

상단에 현재 음반 정보를 축약해 보여주고 아래에 ‘오늘의 곡’의 곡명·아티스트 정보를 표시한다. 행동은 ‘이 곡 듣기’, ‘다음 곡’, ‘이 앨범 감상 완료’다. ‘이 곡 듣기’는 Spotify 등 외부 음원 서비스의 해당 곡 재생 페이지로 연결한다. ‘다음 곡’은 오늘의 곡을 다른 곡으로 변경하며 자체로는 성장 또는 완료 처리하지 않는다. 음반의 일일 경험은 사용자 로컬 날짜 기준 하루 1회 성장에 반영하고, ‘이 앨범 감상 완료’ 실행 시 EXPERIENCED + 큰 나무로 처리한다.
5영화 · 보러가기
현재 영화 정보를 축약해 표시하고 ‘보러가기’를 제공한다. 영화는 일일 경험 기록과 중간 성장을 사용하지 않는다. ‘보러가기’는 OTT 등 외부 시청처 또는 검색 페이지로 연결하며 OTT별 실시간 제공 여부는 판별하지 않는다. ‘이 작품 감상 완료’ 실행 시 EXPERIENCED + 큰 나무로 처리한다.
6콘텐츠별 감상 완료
책은 ‘이 책 감상 완료’, 음반은 ‘이 앨범 감상 완료’, 영화는 ‘이 작품 감상 완료’를 사용한다. 책·음반은 당일 일일 경험 기록 여부와 관계없이 언제든 사용할 수 있다. 실행하면 즉시 EXPERIENCED + 큰 나무로 처리하고 완료 피드백과 선택 평가를 보여준 뒤 다음 추천 후보를 확인할 수 있게 한다.
7주기·재방문
미완료 콘텐츠는 주가 바뀌어도 자동 종료하지 않는다. 선택 다음 날부터는 오늘의 경험을 상단 우선 영역으로 올리고 현재 금주의 콘텐츠는 축약해 표시한다. 책·음반에서 같은 날 완료 버튼을 반복 눌러도 추가 성장하지 않는다.
8평가
콘텐츠별 감상 완료 이후 1~5점 평가는 선택 입력이며 건너뛸 수 있다. 이후 완료 기록 상세에서 입력하거나 수정할 수 있다.
5직접 선택
금주의 추천을 그대로 따르지 않고 사용자가 자신의 경험 전(INTERESTED) 스크랩에서 직접 이번 주 콘텐츠를 고를 수 있다. 직접 선택해도 이후 TODAY-01의 책/음반/영화 경험 흐름과 완료·평가·나의 숲 기록 규칙은 동일하다.

오늘의 경험 기록 · 나무 성장

  • 금주의 추천을 시작하면 씨앗이 생성된다.
  • 책 ‘오늘 독서 완료’와 음반의 일일 경험 기록은 사용자 로컬 날짜 기준 하루 1회만 성장에 반영한다.
  • 일일 기록으로는 씨앗 → 싹 → 덤불 → 나무까지만 성장한다.
  • 책 ‘이 책 감상 완료’, 음반 ‘이 앨범 감상 완료’, 영화 ‘이 작품 감상 완료’를 실행하면 현재 단계와 관계없이 큰 나무가 된다.
  • 영화는 중간 성장 단계를 두지 않는다.
  • 완료 후 1~5점 평가는 선택 사항이며 성장 단계와 별개로 저장한다.
  • 선택 출처 기록: 송림 추천 수락 / 사용자 직접 선택을 구분해 저장한다. 저장→경험 시작률뿐 아니라 추천 수락률과 직접 선택률을 함께 본다.
  • 올해의 숲: 현재 연도 완료 콘텐츠 전체와 IN_PROGRESS 콘텐츠를 탐색하고, 책·음악·영화 완료 수와 최근 완료 콘텐츠 1~2개를 표시한다.
  • 월간 기록: 숲을 반복 생성하지 않고 저장 고유 수·경험 완료 수·주차별 경험 수·콘텐츠 하이라이트로 회고한다.
  • 숲 기록: 현재 연도부터 과거 연도까지 연도별 숲 이미지와 총 경험 수를 최신순으로 표시한다. 연도 선택 시 해당 숲을 화면보다 큰 하나의 이미지로 열어 상하좌우로 이동하며 감상한다.
  • 환경 연출: 새·토끼·개구리 등 작은 애니메이션은 고정/랜덤 환경 연출이며 경험 수·카테고리 비율·평가·저장 횟수에 반응하지 않는다.
  • MVP 제외: 데이터 반응형 숲, 개인별 생성형 테마, 레벨·퀘스트·아이템·수집 보상, 도토리 구매/테마 구매 기능.
