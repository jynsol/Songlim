상황화면과 동작
추천 후보사용자가 관심을 표시하거나 저장한 경험 전 콘텐츠 중 1개를 보여준다. 표지·제목·제작자와 짧은 추천 이유를 표시한다.
추천 이유반복 저장, 최근 저장, 오래 저장해둔 관심을 활용한다. 이유는 실제 저장 데이터에 근거해 표시한다.
이번에는 넘기기현재 후보를 이번 추천 세션에서 제외하고 다음 후보를 보여준다. 후보가 하나뿐이면 숨긴다. 모두 넘기면 처음부터 다시 보기와 직접 고르기를 제공한다.
내가 직접 고를래요TODAY-02에서 경험 전·경험 중 콘텐츠를 유형·검색으로 좁혀 고른다. 추천을 거치지 않고 바로 유형별 경험 영역을 연다.
선택 유지현재 선택은 한 개만 유지한다. 다른 콘텐츠로 바꿔도 이전 기록은 남으며 직접 고르기의 경험 중 목록과 스크랩에서 다시 이어갈 수 있다. 선택 변경 직후 취소를 제공한다.
재방문선택한 콘텐츠의 오늘의 경험을 우선 보여준다. 일주일이 지나도 자동 종료하거나 교체하지 않는다.
완료 후완료를 즉시 반영하고 다음 콘텐츠를 선택할 수 있게 한다. 평가는 선택 사항이다.
후보 없음콘텐츠 저장과 가져오기를 안내한다. 저장하지 않은 새 콘텐츠를 자동 추천하지 않는다.

반복 저장 횟수 내림차순, 최근 저장일 내림차순을 기본 순서로 사용한다. 오래 저장한 콘텐츠는 직접 선택의 ‘오래 저장한 순’에서도 찾을 수 있다. 추천 출처는 송림 추천과 직접 선택으로 구분해 기록한다.

+ 저장URL 붙여넣기 / 사진으로 가져오기 / 직접 검색을 제공한다.
SCRAP-02 · 상세콘텐츠 정보, 출처, 저장 횟수, 현재 상태, 경험 기록과 평가를 보여준다. 오늘의 경험 기록·완료를 바로 실행하거나 현재 콘텐츠로 선택해 이어간다.
정보 수정인식이 틀린 기본 정보는 정보 확인 화면에서 고친다. 경험 기록과 평가는 상세에서 수정한다.
삭제삭제할 항목을 확인한 뒤 사용자의 저장 관계와 관련 기록을 삭제한다. 해당 사용자의 숲·집계에서도 제거하며 다른 사용자의 원본 콘텐츠에는 영향을 주지 않는다.
빈 상태저장 항목이 없으면 + 저장을, 검색 결과만 없으면 검색어·필터 변경을 안내한다.

09나의 숲

숲은 관심과 경험이 쌓인 모습을 보여준다. 개체를 누르면 스크랩과 같은 콘텐츠 상세를 연다.

화면표시와 탐색
FOREST-01 · 올해의 숲가로로 이어지는 2D 숲이다. 열면 현재 선택한 콘텐츠를 첫 기준점에 두고 왼쪽은 비운다. 현재 선택을 포함해 최근 개별 기록을 최대 10개 보여주고 오른쪽으로 둘러본다. 저장만 한 현재 콘텐츠는 씨앗, 경험 중은 싹·덤불, 완료는 나무로 표시한다.
숲의 누적 표현화면에 직접 표시되지 않는 이전 완료 기록은 배경 숲의 밀도로 누적한다. 올해 완료량에 따라 숲이 울창해지고 작은 환경 동물과 애니메이션도 점차 다양해진다. 장식은 콘텐츠 개수를 뜻하지 않는다.
이동과 요약좌우 드래그·스와이프로 탐색하고 작은 위치 표시가 함께 이동한다. 책·음반·영화별 올해 전체 완료 수와 최근 완료 콘텐츠 1개를 보여준다.
FOREST-02 · 월간 기록현재 월을 기본으로 이전 월을 선택한다. 저장한 고유 콘텐츠 수, 완료 수, 유형별 완료 수, 주차별 완료 그래프, 완료 콘텐츠 목록을 보여준다. 미래 월은 선택하지 않는다.
FOREST-03 · 전체 숲 보기현재 연도와 과거 연도를 최신순으로 보여준다. 각 연도에 숲 미리보기와 완료 수를 표시한다. 현재 연도도 선택해 전체 완료 기록을 볼 수 있다.
FOREST-04 · 연도별 전체 숲완료 콘텐츠 1개당 나무 1그루를 넓은 평면에 배치한다. 처음부터 숲 전체를 화면에 거의 꽉 차게 보여준다. 연도와 전체·책·음반·영화 완료 수, 공유 버튼만 간결하게 배치하고 하단 탭은 숨긴다. 핀치·드래그와 전체 보기를 제공한다. 공유 미리보기에는 전체 숲·연도·완료 수를 담고 이미지 저장과 기기 공유 메뉴로 연결한다.
연도별 보존현재 연도는 완료·수정·취소에 따라 갱신한다. 연도가 끝나면 배치와 테마를 보존한다. 과거 기록을 수정하면 같은 테마를 유지하며 해당 나무와 집계를 다시 반영한다.
  • 전체 숲은 첫 진입과 전체 보기에서 모든 나무가 한 화면에 크게 들어온다. 이동 범위는 숲 경계 안으로 제한한다. 나무를 눌러 상세를 볼 수 있도록 콘텐츠 연결을 유지한다.
  • 올해의 숲은 현재 선택 항목을 먼저, 나머지는 올해 최근 경험 기록 순으로 채운다. 최대 10개라는 표시 한도가 완료 집계나 전체 숲의 나무 수를 제한하지 않는다.
  • 완료 수는 완료일 기준으로 집계한다. 연도를 넘겨 이어간 책·음반은 완료한 연도에 나무로 남는다.
  • 기록이 없으면 0개와 빈 숲을 보여준다. 저장 콘텐츠가 있으면 선택을, 없다면 저장을 안내한다.
  • 동물과 위치 표시는 감상을 돕는 연출이다. 별도 조작 과제, 수집, 보상, 레벨을 두지 않는다.

10MY와 공통 동작

항목보이는 내용과 동작
MY-01 · 프로필기본 계정 정보와 저장·경험 상태별 요약을 보여준다. 요약은 스크랩과 동일한 기록에서 계산한다.
취향 데이터 더 입력하기시작 방법 선택으로 이동해 기존 데이터를 유지하며 더 입력한다. 추가 입력을 끝내면 MY로 돌아간다.
오늘의 경험 알림알림은 기본 꺼짐이다. 사용자가 켤 때만 권한과 시간을 설정한다. 거부해도 주요 기능을 이용할 수 있고 권한을 반복 요청하지 않는다.
계정·데이터로그아웃, 회원 탈퇴, 데이터 삭제 범위를 안내한다. 탈퇴·전체 삭제는 영향 범위를 보여주고 확인 후 실행한다.
약관이용약관과 개인정보 관련 문서를 연다.
탐색금주의 추천 / 나의 숲 / 스크랩 / MY 하단 탭을 유지한다. 인증·외부 공유의 집중 화면은 완료 후 원래 흐름으로 돌아간다.
로딩·오류현재 처리 상태와 재시도를 제공한다. 실패해도 입력을 보존하고 취소·뒤로가기가 가능하다.
사용 편의주요 버튼은 한 손으로 누르기 쉽게 배치한다. 충분한 터치 영역과 글자 대비를 확보하며 색상만으로 상태를 구분하지 않는다. 키보드와 화면 읽기 도구로도 이름과 상태를 확인할 수 있게 한다.
기록과 화면 유지일일 기록·완료는 현재 화면에서 처리하고 평가·메모는 선택했을 때만 펼친다. 외부 서비스 이동 전 선택한 작품·곡·스크롤을 보존한다.
다시 이어가기직접 고르기의 경험 중 목록에서 이어간다. 다른 작품 선택이나 완료 취소로 관계없는 작품의 현재 선택을 덮어쓰지 않는다.
취소·실패 복구저장 취소는 이번 저장만 되돌린다. 일괄 저장은 실패 항목만 재시도한다. 기록 수정·취소 결과는 관련 화면에 함께 반영한다.

11데이터와 집계 기준

데이터필수 역할
Content책·음반·영화 원본 정보와 제공처 식별자. 곡은 음반 안의 오늘의 곡을 위한 하위 정보다.
UserContent사용자별 콘텐츠 관계를 한 개만 유지한다. 경험 전 / 경험 중 / 경험 완료 / 싫음, 저장 횟수·최초 및 최근 저장일, 평가를 보관한다.
현재 선택현재 화면에서 이어갈 콘텐츠 ID를 별도로 보관한다. 선택과 링크 클릭만으로 경험 상태를 바꾸지 않는다.
SaveEvent의도적 저장 시점과 출처를 기록한다. 같은 가져오기 묶음의 중복 검출, 요청 재시도는 한 번만 계산한다.
DailyExperience사용자 + 콘텐츠 + 현지 날짜를 고유 기준으로 한다. 페이지·메모는 선택 필드다. 최초 기록으로 경험 중이 된다.
Completion사용자·콘텐츠당 유효 완료 한 건과 실제 완료일을 관리한다. 최초 완료일을 모르는 가져오기·온보딩 기록은 날짜 미상으로 둔다.
성장 상태완료면 나무. 미완료 책·음반은 경험 기록 날짜가 0개면 씨앗, 1개면 싹, 2개 이상이면 덤불이다. 영화는 씨앗 또는 나무다. 별도의 성장 점수는 저장하지 않는다.
ForestYear연도별 테마와 배치 정보를 콘텐츠 ID에 연결한다. 상세 선택이 가능한 데이터를 보존하며 이미지 한 장만 저장해 연결을 잃지 않도록 한다.
집계기준
전체 저장 수사용자의 고유 콘텐츠 수. 반복 저장 횟수와 구분한다.
월간 저장 수선택 월에 유효 저장 이벤트가 있는 고유 콘텐츠 수.
월간·연간 완료 수실제 완료일이 해당 기간에 속한 유효 완료 콘텐츠 수. 날짜 미상은 기간 집계에서 제외하되 전체 경험 완료 목록에는 포함한다.
경험 중유효 일일 기록이 있고 완료하지 않은 책·음반.
변경 반영수정·삭제·취소를 하나의 기준 데이터에 반영하고 스크랩·MY·숲을 같은 결과로 갱신한다. 날짜는 입력 당시 사용자 현지 날짜를 보존한다.
